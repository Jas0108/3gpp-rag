# 3GPP 5G Standards Assistant 
A clean, production-quality **Retrieval-Augmented Generation (RAG)** backend that answers technical questions using **only** the 3GPP TS 23.501 V18.12.0 specification as its knowledge source.

Designed with **LangChain** and a multi-stage **Evidence Sufficiency Gate**, it guarantees that the system **refuses to answer out-of-scope questions** instead of hallucinating.

---

## Key Design Features

1. **Section-Aware PDF Ingestion**: Extracts text page-by-page and parses 3GPP hierarchy (`4.2.2 Network Functions...`) accurately, preserving page numbers and section metadata.
2. **Hybrid Retrieval (Dense + BM25)**:
   - **Dense Search**: `BAAI/bge-base-en-v1.5` embeddings stored in **ChromaDB**.
   - **Sparse Search**: **BM25** keyword search to catch exact 3GPP acronyms (`AMF`, `SMF`, `5QI`, `S-NSSAI`).
   - **Reciprocal Rank Fusion (RRF)**: Merges dense + sparse search rankings.
3. **Cross-Encoder Reranking**: Re-scores top candidates using `ms-marco-MiniLM-L-6-v2` to filter out irrelevant passages.
4. **Evidence Sufficiency Gate**: Rejects queries with low reranker relevance scores ($<0.15$) BEFORE invoking the LLM.
5. **Grounded Generation (LangChain LCEL)**: Uses LangChain `ChatPromptTemplate | LLM | StrOutputParser` with strict system constraints.
6. **Programmatic Citations**: Source citations are generated strictly from chunk metadata—never generated by the LLM.

## How to Run

### 1. Install Dependencies
```bash
pip install -r backend/requirements.txt
```

### 2. Configure Environment
Copy `backend/.env.example` to `backend/.env` and add your API key:
```env
LLM_PROVIDER=openrouter
LLM_MODEL=meta-llama/llama-3.3-70b-instruct:free
LLM_API_KEY=your_api_key_here
```

### 3. Run Ingestion (Pre-indexes the PDF)
From the project root:
```bash
python -m backend.src.ingestion.ingest
```

### 4. Start the Backend API & Frontend Web UI
From the `backend` directory:
```bash
cd backend
uvicorn api.main:app --reload --port 8000
```
- **Frontend Web Interface**: Open `http://localhost:8000` in your browser (or open `frontend/index.html` directly).
- **Interactive API Docs**: `http://localhost:8000/docs`

---

## Evaluation Benchmark

Run the automated evaluation against the 50-question benchmark dataset:
```bash
python -m src.evaluation.evaluator
```

## 🔌 API Endpoints

- **`POST /api/chat`**: Process a user question and receive a grounded answer with section citations.
- **`GET /api/health`**: Health check for ChromaDB, BM25, and LLM configuration.
- **`GET /api/stats`**: Statistics on indexed chunks and specification metadata.
